About the benchmark

The Game Agent Coding League (GACL) evaluates how well language models write game-playing programs, called agents. The models' role ends when they submit the code. The tournament runner executes the agents, which choose every move in Battleship, LieOnce, Wizard, Backgammon, Connect4, WordMatrix, Mancala, and Surround Morris.

Tournament format

Each of the 12 models has two agents per game. In two-player games, each agent plays both agents from every other model. In Wizard, qualifiers select one agent per model to play in the main event, where each table has six different models.

How to read the leaderboard

How agent Elo is calculated

Elo estimates an agent's strength against the other agents in the same game. The ratings are centered at 1500. A 100-point lead over an opponent corresponds to an expected score of about 64%, where a win is worth 1, a draw ½, and a loss 0.

Sequential Elo updates ratings after each result, so changing the match order can change the final ratings. GACL treats all results for a game as if they happened at the same time. We fit all agent ratings together using the full record of wins, draws, and losses for every pair of agents, so reordering the matches gives the same ratings. The fit gives ratings a small pull toward 1500 so even an agent with only wins or only losses gets a finite rating.

In most titles, Elo uses the win, draw, or loss from each individual game.

  • Backgammon counts the outcome of each race (e.g., 5–2, 5–3, etc.), which can span several games.
  • Wizard is rated using main-event games only. Each game has six players. At the end, we compare each player's score with the scores of the other five: a higher score is a win, a lower score is a loss, and equal scores are a draw. For example, scoring 120 points beats an opponent's 100 points. So each game gives every player five results.

Max Elo and Mean Elo

Max Elo
uses the highest agent rating a model achieved in that game. A different agent can be the model's best in each game.
Mean Elo
averages all rated agents from that model in that game, giving each agent equal influence.

If a model's two agents have ratings of 1600 and 1400 in a game, its Max Elo is 1600 and its Mean Elo is 1500. Wizard gives both views the same value because only the model's main-event agent is rated (each main-event game has just one agent per model).

Overall Elo and game weights

Overall Elo is an average of a model's eight game ratings. With Games have different weights selected, multiply each game's Elo by its weight, add the results, and divide by the sum of the weights. With All games have the same weight selected, add the eight ratings and divide by eight. The leaderboard opens with game weights and Max Elo selected.

To set the weights, we take the 12 Max Elo ratings for each game, one per model, and calculate their standard deviation, which measures how spread out the ratings are. We sort the eight games by that spread and assign consecutive weights from 1 for the smallest spread to 8 for the largest. The same weights apply when Mean Elo is selected.

In this tournament, Backgammon (weight 8) has eight times as much influence on weighted Overall Elo as WordMatrix (weight 1). The weight shown on a game tab tells you how much that game contributes to the weighted Overall Elo.

Suppose the league had just two games and a model had an Elo of 1600 in the game with weight 8 and 1420 in the game with weight 1. With game weights, its Overall Elo would be (1600 × 8 + 1420 × 1) ÷ 9 = 1580. With equal weights, it would be (1600 + 1420) ÷ 2 = 1510.

What the game tables show

Each game chart and table shows one result per model. In Max Elo, the table names the model's highest-rated agent, and a suffix such as :2 identifies the agent. Rated games counts that agent's games. In Mean Elo, the table names the model and adds up the games played by its rated agents. Backgammon counts races, and Wizard counts main-event games.

In the head-to-head table, read across a row to see how that model's agents did against the column model's agents. A record of 6–2–2 means six wins, two draws, and two losses. The two draws together add one point, giving 7 out of 10, or 70%. Both Elo views pool all rated agents for each matchup. A dash marks a matchup with no results, including the same-model cells along the diagonal.

Agent Creation

We use these tools to create the agents for the league:

  • Claude agents use the Claude Code VS Code extension.
  • GPT agents use the Codex VS Code extension.
  • Gemini agents use the Antigravity VS Code extension.
  • Open-source agents use DeepSeek Harness (dsh) with OpenRouter credentials.

The benchmark repository also supports generating every agent through OpenRouter. To use that option, configure valid OpenRouter model IDs for the roster.
